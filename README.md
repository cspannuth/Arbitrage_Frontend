# Sportsbook Arbitrage Detector

> The frontend incorporation for my full stack Sportsbook Arbitrage Detector

---

## 📌 Overview

One common issue among just about every person who indulges themselves with gambling is **losing**. 
What if there was a way to gaurantee that a player can always beat the sportsbook? That is where 
Arbitrage betting comes in, and serves as a way to gaurantee profit and abuse poorly places lines
within the market. This react based website ties into the backend to display data, allow user interaction,
and authenticate user specific fetch calls! See the backend repository [here](https://github.com/cspannuth/Arbitrage_Engine) that
incorporates it!

---

## 🚀 Features
- React based interactive website with full backend incorporation
- Live API processing from the backend
    - Includes user specific filtering 
- Email based user authentication
- Encrypted JWT authentication tokens for data fetching
- Live upon demand fetching of arbitrage opportunities in real sportsbook markets
- Support for various types of bets and markets
